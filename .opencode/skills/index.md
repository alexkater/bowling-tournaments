# Project Skills

Skills reutilizables para el proyecto:

| Skill | Cuándo usarlo |
|---|---|
| `db-schema` | Añadir nueva tabla a la base de datos |
| `trpc-router` | Crear nuevo router tRPC o añadir endpoints |
| `tournament-flow` | Implementar feature que atraviesa shared → db → api → web |
| `scoring-engine` | Puntuaciones, handicap, clasificaciones, tiebreakers |
| `auth-setup` | Configurar auth en API, web o mobile |
| `payment-flow` | Integrar pagos con Stripe |
