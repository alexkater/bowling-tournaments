# Functional Requirements

## V1 (MVP)

### Core Tournament Management
- [ ] Crear torneo con config (formato, handicap, fechas, centro)
- [ ] Publicar torneo con página pública
- [ ] Registro de jugadores (online, con pago)
- [ ] Gestión de squads y asignación de carriles
- [ ] Ingreso de puntuaciones (manual, por juego)
- [ ] Cálculo automático de handicap
- [ ] Clasificaciones en vivo (auto-refreshing)
- [ ] Resultados públicos (link compartible)

### Brackets (Sidepots)
- [ ] Brackets de 8 personas (forward/reverse)
- [ ] Shuffle aleatorio con algoritmo de fairness
- [ ] Actualización de resultados en vivo
- [ ] Reporte de "still alive"
- [ ] Gestión de pagos de brackets

### Sidepots
- [ ] High game / High series (scratch + handicap)
- [ ] Eliminators con auto cut-lines
- [ ] Big Dog / Blind Draw
- [ ] Smart payouts (decaimiento geométrico)

### Players
- [ ] Perfil de jugador (averages, USBC ID)
- [ ] Historial de torneos
- [ ] Página pública de resultados

### Organization / Admin
- [ ] Multi-organización (centros de bowling)
- [ ] Reportes PDF (standings, lane assignments, financials)
- [ ] Dashboard del torneo (pinned)

## V2

### Advanced Tournament Features
- [ ] Stepladder finals (4-5 personas)
- [ ] All-Events (singles + doubles + teams combinados)
- [ ] Multi-squad (combined or separate standings)
- [ ] Season points tracking
- [ ] Clone tournament (con o sin jugadores)
- [ ] Bracket rollover (auto redistribución)
- [ ] Waitlist con auto-promotion

### Integrations
- [ ] Integración con sistemas de scoring (Brunswick Sync, QubicaAMF, Steltronic)
- [ ] Publicación a iBowlTournaments
- [ ] Conexión con USBC database (lookup)
- [ ] Stripe Connect para pagos

### Mobile Player App
- [ ] Ver brackets y sidepots en vivo
- [ ] Notificaciones push (próxima ronda, resultados)
- [ ] Check-in móvil
- [ ] QR scanner para resultados

### Operations
- [ ] Lane crossing planner con simulador
- [ ] Offline score entry con auto-sync
- [ ] Multi-user con roles
- [ ] Reportes financieros avanzados
